# WebStudio — HTML & CSS Homework #2

A WebStudio landing page developed for **GoIT HTML & CSS — Module 2: Introduction to CSS**.

## Live website

[View the WebStudio page on GitHub Pages](https://fedorstoiets.github.io/goit-markup-hw-02/)

## Features

- Semantic HTML5 structure and accessible text alternatives for images
- Header with section navigation and functional email/phone links
- Hero section with a call-to-action button
- Features, Team, and Portfolio sections
- Footer with brand identity and business description
- Styles organized in separate CSS modules
- Google Fonts: Roboto and Raleway
- modern-normalize CSS reset
- Hover and keyboard-focus styles for interactive elements

## Technologies

HTML5, CSS3, Git, GitHub Pages, and Prettier.

## Project structure

```text
goit-markup-hw-02/
├── css/
│   ├── common.css
│   ├── header.css
│   ├── hero.css
│   ├── features.css
│   ├── team.css
│   ├── portfolio.css
│   ├── footer.css
│   └── main.css
├── images/
│   ├── team-1.jpg ... team-4.jpg
│   └── portfolio-1.jpg ... portfolio-6.jpg
├── index.html
└── README.md
```

The HTML file links only to `css/main.css`, which imports the seven modules in the prescribed order.

## Run locally

Clone the repository and open `index.html` in a web browser:

```bash
git clone https://github.com/fedorstoiets/goit-markup-hw-02.git
```
